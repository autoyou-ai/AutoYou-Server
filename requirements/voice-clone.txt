# (Resemble AI, MIT), the engine behind the custom voice TTS provider.
#
# Installed by scripts/install_voice_clone_runtime.py, never into the server
# environment. The installer puts torch and torchaudio in first, chosen for the
# machine's GPU, installs this file under a constraint that keeps that torch,
# then installs chatterbox-tts==0.1.7 with --no-deps so its torch==2.6.0 pin
# cannot replace the GPU build.

# chatterbox-tts 0.1.7 asks for transformers==5.2.0 and diffusers==0.29.0,
# which have published advisories (remote-code and path-traversal issues). The
# October 25 GPU speech comparison used transformers 5.12.1 and diffusers
# 0.38.0. Python 3.10 retains that pair. Python 3.11 and later use the
# transformers release in the server lock.
#

# Gradio demo and loudness tools are left out.
