# Voice-clone runtime: a separate Python environment for Chatterbox
# (Resemble AI, MIT), the engine behind the custom voice TTS provider.
#
# Installed by scripts/install_voice_clone_runtime.py, never into the server
# environment. The installer puts torch and torchaudio in first, chosen for the

# which have published advisories (remote-code and path-traversal issues). The
# patched releases below were checked on 2026-10-25 with a full GPU build and
# speech run: same clip choice, watermark, intelligibility and speed.
# transformers matches the server's audited lock.
#
# Only what the English model imports is listed; the multilingual tokenizers,
# Gradio demo and loudness tools are left out.
