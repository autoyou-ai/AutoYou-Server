# Earth map data

`ne_110m_admin_0_countries.txt` is the Natural Earth Admin 0 country-boundary dataset at 1:110m resolution, vendored as JSON text from:

<https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson>

Natural Earth data is public-domain map data. The dashboard uses the geometry locally, with an equirectangular WGS84 longitude/latitude projection. IP coordinates remain coarse network-location signals and are never treated as exact device or person locations.
