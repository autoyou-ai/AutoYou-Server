Checklist

What Makes a Valid Game?

  • Self-contained UTF-8 HTML with a standard <head> element (up to 8 MiB; larger games use .aygame packages up to 5 GiB).
  • In-game Quit button: Include a visible Quit (×) button that calls AutoYouGame.quit() so mobile players exit cleanly without overlaid system chrome.
  • Offline-first: Keep styles, sprites, and scripts inline or inside the package so games play smoothly without internet access.
  • Touch + Keyboard friendly: Support pointer/touch events alongside arrow keys or WASD.

Input & Engine Contract

            
Touch frames carry up to 10 normalized pointers in [0, 1], accelerometer/gyroscope in SI units, analog axes in [-1, 1], and digital button down/up events. Local engines authenticate once via /api/webrtc/game-input/connection and stream from /api/webrtc/game-input/stream.
