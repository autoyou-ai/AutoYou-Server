Purpose
- Agent: `antigravity_agent`
- App ID: `antigravity_desktop`
- Transport: `desktop_gui`
- Scope: User-calibrated local desktop controls for an installed Antigravity app.

Working Directory Strategy
- Mode: `prefix_prompt`
- Prompt template: `[Workspace: {working_directory}]

- Copy response target: `copy_response_button`

Crowd-Sourcing Rules
- Keep each new screenshot pack versioned with a stable `asset_pack_id` and a `valid_until` date.
- Prefer window-relative coordinates when possible; use screen-relative coordinates only as a fallback.
- When replacing screenshots, update both `manifest.json` and this `llm.txt` so future LLMs inherit the new visual map.
- Never delete an older pack until a newer pack has been validated on the target OS build.

Future Maintenance
- Add new screenshots under `desktop_assets/images/...` and reference them from the matching target entry.
- If a UI version stops matching before its `valid_until` date, shorten the date and add a replacement pack.
- Record whether the app was maximized, windowed, or on a scaled display when the pack was captured.
