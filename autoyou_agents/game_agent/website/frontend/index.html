Game agent

Design a game

Describe the host game, input mapping, and engine you want to use. The agent can draft a plan and adapter code.

Publish a phone game

Choose one self-contained UTF-8 HTML file with a <head> element, under 511 KB. Publishing a file with the same name replaces that game's server copy. The paired Android and iOS apps download it when selected.

Start a native session

  1. For on-device play, publish the HTML game above, then reopen Games on this computer in the paired Android or iOS app.
  2. For host play, enable Remote Desktop video, screen control, Game mode, and Share this computer's sound in Video & Calls. Set up to four Game buttons with labels and engine names there.
  3. Launch Neon Horizon on the captured monitor and make it full screen. It connects to the local game input stream so the native joystick, touch, tilt, and buttons drive the game.
  4. On a connected iOS or Android device, choose Play game. The native session opens full screen with camera and microphone off.
Input contract

Full state where it matters

Touch frames contain the complete active pointer set, up to ten IDs, with coordinates from 0 to 1. Sensors send x/y/z in SI units. Joystick axes range from −1 to 1. Buttons send down and up transitions. state_reset with all_sessions clears every player's held state after backlog loss; session_end clears one player.

Engine boundary

One loopback subscriber

An admin authenticated request to /api/webrtc/game-input/connection returns a process scoped stream credential. The local engine connects to /api/webrtc/game-input/stream over WebSocket. Browser games can use the host's mouse and keyboard directly; Unreal and other engines can parse the local JSON stream for player IDs, touch, motion, joystick, custom button names, mouse, and keyboard. The stream accepts one consumer and never exposes input directly to the public website.

Media and control path

Host game→WebRTC video + audio→iOS / Android app→WebRTC control→Local engine

The Unreal plugin exposes frames and session resets through a Game Instance subsystem; its README covers installation and Blueprint binding. The Python adapter shows held state mapping for other engines. The game remains a normal host application, so no engine binary is uploaded to AutoYou.

Game Studio is an opt in agent website. Host game controls require an active video session and a valid control lease.
