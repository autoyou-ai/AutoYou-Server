# Security Console

The **Security** screen (`renderSecurityScreen()` in `assets/admin-ui.js`) holds the controls for how devices pair with your server and how its data is protected. The API behind each control is in [Security & TOTP APIs](/api-reference/security-and-totp), and the model behind it is in [Security & Authentication](/architecture/security-and-auth).

These controls change credentials and the security posture, so they work only from the computer itself or from an HTTPS admin session opened directly on the admin port. A paired device's browser can read the console but cannot change them.

---

## Security mode and pairing tier

- **Security mode** switches between Normal, Secure Mode, Secure Professional, and Secure Professional Maximus. The help text under the selector describes the selected mode. See [Security Modes](../security/security-modes.md).
- **Pairing security tier** switches between **Quick Pairing**, where a client can pair with one chat message, and **Enhanced Pairing**, which adds an extra round trip for every client and makes password guessing harder.

Each has its own save button (`POST /api/admin/security/mode` and `POST /api/admin/security/tier`). Leaving Maximus decrypts the protected stores back to plaintext, and the console warns on every screen if any protected store was left sealed and needs a restart of the services that hold it.

---

## Password

The password panel changes the server password used by pairing and secure-mode flows (`POST /api/admin/password`). The new password must be entered twice and pass a strength check that rejects short and very common passwords. A built-in generator (`POST /api/admin/password/generate`) offers a strong random one. Changing the password re-encrypts the configuration under it.

---

## Authenticator

The authenticator panel (`renderTotpManagementBody()`) manages the one shared authenticator used for Secure Professional pairing, authenticator pair-code mode, and elevation for the admin agent.

1. **Set up** creates a new secret and shows a QR code and a setup link (`showTotpSecretModal()`). Scan the QR code with an authenticator app, or copy the setup key.
2. **Import** replaces the secret with an existing Base32 secret or authenticator link, for example when moving to a new computer.
3. **Show** and **current code** display the saved secret and the code it produces now.
4. **Delete** removes the saved secret.

The server does not generate recovery codes.

---

## Automatic Configuration Setup

This panel creates a setup QR code that configures a supported Android or iOS app in one scan (`GET /api/settings/export-qr`). **The QR code contains your server password and the shared authenticator secret.** Show it only on a screen you control and never share a screenshot of it. See [Pairing & Device Discovery](/architecture/pairing-and-discovery#setup-qr-code-automatic-configuration).

---

## Per-agent 2FA profiles

Agent websites such as the Persona agent can require their own second factor. This panel issues independent 2FA profiles and assigns each to an agent website.

- A profile's secret is derived from the server password and is not stored, so it is shown **once**, when the profile is created. The console cannot show it again.
- **Assign** attaches a profile to an agent. **Wipe** on an agent removes its assignment. **Wipe** on a profile deletes the profile, and every agent that used it loses its 2FA requirement.
- Recovery means wiping the profile and creating a new one.

---

## Prompt Override

Prompt Override is an advanced control for locked runtimes. The root agent's instructions are locked in packaged runtimes. When Prompt Override is active, the saved override prompt takes precedence over the built-in one, and the change takes effect on the next restart. Activating it records an acknowledgement that you accept responsibility for custom prompts and for changes to the safety behavior built into AutoYou (`POST /api/jailbreak/activate`; `POST /api/jailbreak/deactivate` removes it). The console marks an active override in red. Leave it inactive unless you know why you need it.

---

## Maximus storage key

In Maximus mode, the console can rotate the storage key (`POST /api/admin/security/storage/rotate`). It re-encrypts the protected files under a new key and reports how many were re-encrypted. It restarts the AI Agent worker if it was running.

---

## Home network exposure

When pages or the admin console are exposed to other devices on your home network, the console shows the URLs they can open and warns if they would be served over plain HTTP, readable by anyone on the same Wi-Fi.
