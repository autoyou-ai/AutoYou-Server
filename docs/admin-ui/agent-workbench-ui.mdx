# Agents & Agent Studio

The **Agents** screen (`renderAgentScreen()` in `assets/admin-ui.js`) is where you edit the main agent's system prompt, install or build sub-agents, and open **Agent Studio** to manage an agent's instructions and website. The routes are in the [route catalog](/api-reference/route-catalog); the agents themselves are listed in the [Agent Catalog](/agents/system-and-admin).

---

## Panels

| Panel | What it covers |
| :--- | :--- |
| **Agent Studio** | Pick the agent to manage, then work through its lifecycle, instructions, and website. It defaults to the main AutoYou agent. |
| **System Prompt - Main Agent** | The main agent's root prompt. It governs the assistant's overall personality and behavior and sits above every installed sub-agent. |
| **Installed agents** | Sub-agents currently loaded into AutoYou AI. Open one in Agent Studio, or toggle its website. |
| **Available to install** | Sub-agents and drafts that are ready to install. |
| **Create New Agent** | Set up a new agent draft that you can then open in Agent Studio. |

## Installing and managing agents

| Route | Purpose |
| :--- | :--- |
| `GET /api/agents/manage` | The overview payload for Agent Studio |
| `POST /api/agents/install` | Mark an agent installed and register its runtime metadata |
| `POST /api/agents/uninstall` | Mark an agent uninstalled. Its source files are not removed. |
| `POST /api/agents/install-builder-suite` | Install the conservative Agent Builder workflow suite in one call |
| `POST /api/agents/frontend` | Enable or disable an agent's browser-facing control |
| `POST /api/ai/restart` | Reload the AI Agent runtime after agent or prompt changes |

## Instructions

An agent's instructions live in its `prompt.py`.

- `GET /api/agent-instructions` reads the main agent's instructions, and `POST /api/agent-instructions` updates them.
- `POST /api/agent-instructions/sections` updates the editable prompt section variables and regenerates `AGENT_INSTRUCTION`.
- `POST /api/agent-instructions/revert` restores `AGENT_INSTRUCTION` to `DEFAULT_INSTRUCTION`.
- `POST /api/agents/workbench/{agent_name}/instructions` saves instruction content for an agent draft.

In packaged runtimes the root instructions are locked and read-only. **Prompt Override** on the Security screen unlocks editing; the edits are saved to a local override file and apply on the next restart. See [Security Console](security-console.mdx).

## Drafts: the workbench

Changes to an agent are made in a **workspace draft** and then published to the live agents directory.

| Route | Purpose |
| :--- | :--- |
| `POST /api/builder/create` | Scaffold a new workspace draft |
| `GET /api/builder/agents` | List live agents and workspace drafts |
| `GET /api/builder/status/{agent_name}` | Detailed studio state for one agent |
| `GET /api/agents/workbench/{agent_name}` | Workbench detail for one agent |
| `POST /api/agents/workbench/{agent_name}/clone` | Clone a live agent into a workspace draft |
| `POST /api/agents/workbench/{agent_name}/test` | Run a **structural check** on a draft. It checks the draft's structure; it does not run the agent's tools. |
| `POST /api/agents/workbench/{agent_name}/publish` | Publish a draft to the live agents directory. Body: `{"install_after_publish": true}` to install it as well. |
| `POST /api/agents/workbench/{agent_name}/discard` | Discard a draft |
| `POST /api/agents/draft/{agent_name}/publish`, `POST /api/agents/draft/{agent_name}/discard` | The same actions, used by the Agent Builder agent |

### Agent websites

An agent can have a web interface under its `website/frontend/` folder, served by the [page service](/api-reference/website-gateway) at `/agent/{agent_name}/`.

| Route | Purpose |
| :--- | :--- |
| `POST /api/agents/workbench/{agent_name}/frontend/scaffold` | Scaffold frontend assets for a draft |
| `POST /api/agents/workbench/{agent_name}/frontend/manifest` | Save the draft's frontend manifest |
| `POST /api/builder/agent_port` | Register a dynamic HTTP port forward for an agent's web server |

How a website is reached, and who may open it, is covered in [Agent Websites & Bookmarks](/api-reference/websites-and-bookmarks) and [Security & TOTP APIs](/api-reference/security-and-totp#per-agent-2fa-profiles).
