# Overview & System Health

The **Overview** view (`renderOverview()` in `assets/admin-ui.js`) serves as the primary mission control dashboard for AutoYou Server operators. It delivers a real-time summary of hardware metrics, active client sessions, background service statuses, and scheduled tasks.

## Component Breakdown in `admin-ui.js`

### 1. `renderOverviewQuickControls()`
Renders interactive action chips for immediate system operations:
- **Restart Server Core**: Dispatches `POST /ai-agent-server/restart` to reboot agent workers without dropping WebRTC connections.
- **Toggle Screen Listen**: Toggles passive desktop activity observation via `POST /api/screen-listen`.
- **Purge Temporary Files**: Cleans up expired cache files, dangling audio temporary files, and stale database WAL checkpoints.

### 2. `renderOverviewServiceRow()`
Iterates over all internal and companion subprocesses returned by `GET /api/status` and `GET /api/autoyou-page-service/status`:
- Displays green/amber/red operational badges.
- Displays restart buttons beside failing services.
- Surfaces companion process crash logs directly in collapsible drawer dialogs.

### 3. `renderOverviewAccessPanel()`
Calculates and renders all reachable network routes:
- **LAN Local Pair IP**: Resolved dynamically by `shared/local_network_info.py`.
- **Agent Websites Directory**: Quick links to open active agent web apps on port `8067`.
- **Public Tunnel Status**: Shows Tunnelmole HTTPS domain if active.

### 4. `renderSchedulerQueue()`
Pulls real-time telemetry from `GET /api/scheduler/live-summary` and renders:
- Pending scheduled notifications (e.g. reminders, cron triggers).
- Active background tasks and progress bars.
- Alarms and pending agent invocation jobs.

### 5. `renderBootSweepHistory()`
Presents an audit log of startup initialization checks:
- Keystore integrity verification.
- Database schema migrations and index checks.
- Optional dependencies scan (Node, Docker, Ollama, Playwright).
