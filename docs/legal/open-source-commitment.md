# Open-Source Commitment

AutoYou is built on the work of open-source developers. OpenStorey LLC
("OpenStorey") commits to setting aside a percentage of the money it raises
through [www.autoyou.me/donate](https://www.autoyou.me/donate/) for the
open-source developers credited at
[www.autoyou.me/attributions](https://www.autoyou.me/attributions/), and to give
as much as it can.

This commitment is why AutoYou Server is source-available rather than open
source, and why the [LICENSE](../../LICENSE) does not allow the code to be used
to train AI models. It keeps the project sustainable enough to keep the
commitment.

## Current period

OpenStorey sets this value and announces it before each period starts. A period
is a calendar quarter.

| Setting | Value |
| --- | --- |
| Percentage of net money raised set aside for open-source developers | Not yet announced |

## How it works

- **Money raised.** "Net money raised" is the money OpenStorey actually receives
  through the [donate page](https://www.autoyou.me/donate/), after platform and
  payment fees, taxes, refunds, and chargebacks.
- **Set aside.** For each period, OpenStorey sets aside the announced percentage
  of the net money raised in that period.
- **Recipients.** The developers and projects credited on the
  [attributions page](https://www.autoyou.me/attributions/) at the start of the
  period. OpenStorey chooses how to divide the amount among the recipients that
  can receive money, and publishes the method it used.
- **Payment.** Through the routes those developers already accept, for example
  GitHub Sponsors, Open Collective, or thanks.dev.
- **Report.** After each period, OpenStorey publishes the percentage, the total
  set aside, and the projects paid.

## What this is not

This is a commitment about how OpenStorey uses the money it raises. It does not
give any developer or project a right to a particular payment, and amounts
depend on the money actually raised. It is separate from the
[Contributor Pool](../contributors/contributor-pool.md), which shares money with
the people who contribute to AutoYou Server.
