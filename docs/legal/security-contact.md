# Security Contact

Report security vulnerabilities to:

```text
security@autoyou.me
```

For privacy requests or data-handling questions, contact `privacy@autoyou.me`. For product help, use [www.autoyou.me/support](https://www.autoyou.me/support/).
The full policy is in [SECURITY.md](../../SECURITY.md).

Please include:

- affected version or artifact
- operating system and app variant
- reproduction steps
- impact summary
- whether the issue is already public

Do not include secrets, private keys, unrelated personal data, or third-party conversation content in the initial report.

AutoYou prioritizes reports involving authentication bypass, local data exposure, pairing abuse, command execution, unsafe tool execution, and private message disclosure.
