# Agent Web Frontends

Many AutoYou agents provide rich visual user interfaces in addition to conversational abilities. The browser proxy on **port 8067** serves these static and dynamic web frontends under `http://127.0.0.1:8067/agent/{agent_name}/`.

---

## Directory Structure

To equip an agent with a web interface, create a `website/frontend/` folder inside the agent package:

```
autoyou_agents/currency_agent/
├── agent.py
├── manifest.json
└── website/
    └── frontend/
        ├── index.html       # Single-page UI entrypoint
        ├── app.js           # Client logic and API fetch calls
        ├── style.css        # Responsive styling
        └── icon.png         # 64x64 agent icon
```

## Starter Web Frontend Example

### 1. `index.html`
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Currency Converter</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <h2>Currency Converter</h2>
    <div class="form-group">
      <input type="number" id="amount" value="100" />
      <select id="from-currency">
        <option value="USD">USD</option>
        <option value="EUR">EUR</option>
        <option value="GBP">GBP</option>
      </select>
      <span>to</span>
      <select id="to-currency">
        <option value="EUR">EUR</option>
        <option value="USD">USD</option>
        <option value="JPY">JPY</option>
      </select>
      <button onclick="handleConvert()">Convert</button>
    </div>
    <div id="result" class="result-box"></div>
  </div>
  <script src="app.js"></script>
</body>
</html>
```

### 2. `app.js`
Communicates with the server using standard Fetch APIs:

```javascript
async function handleConvert() {
  const amount = parseFloat(document.getElementById('amount').value);
  const from = document.getElementById('from-currency').value;
  const to = document.getElementById('to-currency').value;

  const resultBox = document.getElementById('result');
  resultBox.textContent = 'Calculating...';

  try {
    // Invoke agent tool via server chat or dedicated endpoint
    const response = await fetch('/api/chat', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        message: `Convert ${amount} ${from} to ${to}`,
        agent_override: 'currency_agent'
      })
    });

    const data = await response.json();
    resultBox.textContent = data.reply;
  } catch (err) {
    resultBox.textContent = `Error: ${err.message}`;
  }
}
```

## Route Modes (`manifest.json`)

In `manifest.json`, configure how the browser proxy handles requests:

```json
{
  "name": "currency_agent",
  "has_frontend": true,
  "route_mode": "path_proxy",
  "proxy_port": 8067
}
```

- **`path_proxy` (Default)**: Static files are served directly by the FastAPI web gateway on port `8067` at `/agent/{agent_name}/`.
- **`direct_forward`**: Used for agents running a separate internal HTTP server. Requests are reverse-proxied to that internal port.

## Managed Backend Processes

An installed agent can declare an external website service in `website/manifest.json`. AutoYou starts it when the agent is installed and its website is enabled, registers its loopback port for `/agent/{agent_name}/` proxying, and stops it when the website is disabled, the agent is removed, or the server shuts down. This works for a Rust service as well as other executables.

The Rust website scaffold (`backend_stack: "rust_axum"`) writes a managed process declaration that runs `cargo run --release`. That path requires Rust/Cargo on `PATH`; a packaged agent can instead point `command` at its platform-specific, prebuilt executable.

```json
{
  "agent_name": "rust_agent",
  "title": "Rust Agent",
  "requires_proxy_registration": true,
  "backend_stack": "rust_axum",
  "managed_runtime": {
    "type": "process",
    "command": ["cargo", "run", "--release", "--", "--port", "{port}"],
    "working_directory": "website/backend",
    "health_path": "/health",
    "startup_timeout_seconds": 600,
    "shutdown_timeout_seconds": 10
  }
}
```

The process is launched directly without a shell from inside the agent package. Relative executable and working-directory paths must remain inside that package. AutoYou passes `HOST=127.0.0.1`, `PORT`, and the equivalent `AUTOYOU_HOST` / `AUTOYOU_PORT` values. The service should listen on that loopback port and provide an HTTP health route; the manifest's `health_path` is optional.

For a Docker Compose backend, declare `type: "docker-compose"` and a `compose_file` path relative to the agent package. Compose should bind its published host port using `${HOST:-127.0.0.1}:${PORT}:<container-port>`; the service inside the container listens on `0.0.0.0`. AutoYou assigns a private, stable Compose project to each installed agent and shuts down only that project with `docker compose down --remove-orphans`. Its named volumes and images are retained.

Only installed agents with `requires_proxy_registration: true` and an enabled website are started. Missing executables, Cargo, Docker, or an unhealthy service leave the frontend unregistered and are logged by the server.
