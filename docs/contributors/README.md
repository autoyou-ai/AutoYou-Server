# Contributor and AI Maintainer Guide

This directory contains the public instructions for people and AI assistants
working on AutoYou Server.

- [LLM.txt](LLM.txt) is the compact repository context.
- [AGENTS.md](AGENTS.md) is the general agent contract.
- [CLAUDE.md](CLAUDE.md) and [CODEX.md](CODEX.md) provide assistant-specific entry points.
- [TESTING.md](TESTING.md) is the human-readable validation guide.
- [TESTING_SKILL.md](TESTING_SKILL.md) and [TEST_RUNNER_AGENT.md](TEST_RUNNER_AGENT.md) are reusable validation instructions.
- [autoyou-server-validate](../../.agents/skills/autoyou-server-validate/SKILL.md) is the Codex skill for focused checks and explicitly requested isolated local end-to-end tests.

These guides complement [CONTRIBUTING.md](../../CONTRIBUTING.md),
[SECURITY.md](../../SECURITY.md), and [tests/README.md](../../tests/README.md).
