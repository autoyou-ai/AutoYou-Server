# Security & Privacy

AutoYou is designed so your personal work stays on your computer by default.

## What Is Protected

| Area | Protection |
| --- | --- |
| Phone connection | Encrypted app connection between your device and computer |
| Cloud Pair setup | Short-lived pairing details only |
| Local notes and history | Stored on your computer |
| Cloud AI requests | Sent only when you choose a cloud AI provider |

## What Stays Local

- Chat history
- Notes and memory
- Attached files
- Local helper settings
- Personal server configuration

## Optional Cloud Use

Cloud Pair can help your phone find your computer. Cloud AI providers can answer model requests when you choose them. AutoYou does not use those paths for local notes, files, or saved memory unless a feature clearly asks for it.

## Good Security Habits

- Use a strong server password.
- Use Secure or Secure Professional mode on shared or public networks.
- Keep your operating system and AutoYou app updated.
- Use full-disk encryption on laptops that travel.
