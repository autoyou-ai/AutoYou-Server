# Agent Websites & Bookmarks APIs

These endpoints govern how agent web frontends are served over port `8067`, route modes, session revocation, and browser bookmarks.

---

## In-Process Website Gateway & Page Service (`routers/website_gateway.py`)

In standard home network deployments (`path_proxy` mode), only the admin port listens beyond loopback. A remote browser on another device authenticates over HTTPS and reaches every hosted agent web application under `/agent/{agent_name}/` on that same origin.

Each request is handed directly to the **Page Service in-process**: no second listener, no extra hop, and identical media streaming and WebSocket capabilities.

### In-Process Gateway Routes (Admin Origin: `:8123` / `:8443`)

The following paths are intercepted on the admin origin and forwarded in-process to the page service:

```http
GET   /websites
GET   /agent-websites
GET   /agent-frontends
GET   /api/websites
GET   /api/agent-websites
QUERY /api/agent-websites
GET   /api/agent-frontends
GET   /api/agent-directory
ALL   /agent/{agent_name}
ALL   /agent/{agent_name}/{proxy_path:path}
```

### `GET /agent/{agent_name}/`
Renders the single-page application bundled with an agent (`autoyou_agents/{agent_name}/website/frontend/index.html`).

#### Example URLs
- Audio Agent: `http://127.0.0.1:8123/agent/audio_agent/` (or port `8067` directly)
- Notes Agent: `http://127.0.0.1:8123/agent/notes_agent/`
- Files Agent: `http://127.0.0.1:8123/agent/files_agent/`
- Education Agent: `http://127.0.0.1:8123/agent/education_agent/`

### Remote Browser Identity Translation
When a paired tablet, phone, or laptop browser accesses an agent website through the gateway, the server automatically stamps and forwards remote identity headers (`REMOTE_BROWSER_IDENTITY_HEADERS`), ensuring the agent frontend receives the client's authenticated role without re-challenging for administrative credentials.

## Page Feed Process & Social Publisher (`page_feed.db`)

Powers `page_agent` to publish social feed items, media updates, and agent outputs to connected client streams.

- **Storage**: SQLite database at `page_feed.db`.
- **Feed Features**:
  - Full-text search across authored posts and media cards.
  - Video and audio chunk streaming supporting HTTP 206 Partial Content range requests.
  - Atomic post deletion and draft caching.

## RFC 10008 Agent Website Search

### `QUERY /api/agent-websites`
Implements the [RFC 10008 HTTP QUERY](https://www.rfc-editor.org/rfc/rfc10008.html) specification for rich searching across registered agent frontends without passing parameters in the URL query string.

<CodeGroup>
```bash cURL
curl -X QUERY http://127.0.0.1:8067/api/agent-websites \
  -H "Content-Type: application/json" \
  -H "Accept-Query: application/json" \
  -d '{
    "query": "audio player and recording",
    "limit": 10
  }'
```

```python Python
import requests

resp = requests.request(
    "QUERY",
    "http://127.0.0.1:8067/api/agent-websites",
    json={"query": "audio player and recording", "limit": 10}
)
print(resp.json())
```
</CodeGroup>

#### Response (`200 OK`)
```json

  "matches": [
    {
      "name": "audio_agent",
      "title": "Audio Player & Library",
      "route": "/agent/audio_agent/",
      "description": "Full playback library, playlist management, and local audio streaming.",
      "relevance_score": 0.94
    },
    {
      "name": "voice_training_agent",
```

## Website Route Modes & Security

### `GET /api/agent-websites/security`
Returns routing modes for all agent websites (`path_proxy` vs `direct_forward`).

#### Response (`200 OK`)
```json
{
  "routes": {
    "audio_agent": { "route_mode": "path_proxy", "port": 8067 },
    "mac_security_agent": { "route_mode": "direct_forward", "port": 8101 }
  }
}
```

### `POST /api/agent-websites/sessions/sign-out-all`
Immediately invalidates all active session cookies and tokens across all hosted agent websites.

## Browser Bookmarks Management

### `GET /api/bookmarks`
Returns saved bookmarks used by the internal browser agent and connected desktop clients.

### `POST /api/bookmarks`
Saves a new bookmark into the local SQLite database.

#### Request Payload
```json
{
  "title": "FastAPI Documentation",
  "url": "https://fastapi.tiangolo.com",
  "category": "Development"
}
```

### `DELETE /api/bookmarks/{bookmark_id}`
Deletes an individual bookmark.
