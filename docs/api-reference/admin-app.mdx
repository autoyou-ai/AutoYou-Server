# Admin App Reference

The admin app is the first of the two FastAPI applications that `server.py` creates with `create_apps()`. It serves the web console and the management API that the console, the desktop and mobile apps, and paired devices use.

- **Port:** `8001` by default (`AUTOYOU_ADMIN_PORT`). A TLS listener on `8443` is offered when the server is bound beyond loopback. The default bind host is `127.0.0.1`.
- **Console:** `GET /` and `GET /admin` serve the single-page console, whose code is `assets/admin-ui.js` and `assets/admin-ui.css`. `GET /legacy` serves an older dashboard.
- **Routes:** every route is listed in the [route catalog](/api-reference/route-catalog). The catalog is generated from the source, so it is the authoritative list.

The [auth app](/api-reference/auth-app) is the separate pairing surface. Some routes, such as the unlock routes, are registered on both apps.

## Signing in

| Route | Purpose |
| :--- | :--- |
| `GET /login`, `POST /login` | The sign-in page and the form that creates an admin session |
| `GET /logout` | End the session |
| `POST /api/login/native-unlock` | Sign in from the computer itself with the server password saved in the operating system's credential store. Loopback only, and it can be turned off with `security.native_unlock_enabled`. |
| `POST /api/login/factory-reset` | Erase AutoYou's local data and shut the server down. Loopback only, and the body must contain `{"confirmation": "RESET"}`. |

A successful sign-in sets the `admin_session` cookie. The server also accepts a bearer token from `POST /api/admin/session/verify`, which exchanges a valid authenticator code for a token that lasts one hour. `GET /api/admin/session/capabilities` reports whether an authenticator is configured. The credential model, session lifetime, and the limits on remote browsers are described in [Security & Authentication](/architecture/security-and-auth).

While the server is `SetupPending` or `Locked`, API paths return `451` or `401` and browser paths redirect to `/login`.

## Route groups

| Group | Source | What is in it |
| :--- | :--- | :--- |
| Admin and configuration | `routers/admin.py` | Bootstrap, configuration, password and security settings, authenticator setup, the chat and conversation API, status, scheduler summaries, and setup recipes |
| Console and sign-in | `routers/admin_ui.py` | Console pages and assets, sign-in, native unlock, factory reset, software updates, guides, and legal documents |
| Agents and Agent Builder | `routers/agents.py` | Agent catalog and install state, the workbench, agent website frontends, bookmarks, provider status, and per-agent 2FA profiles |
| Pairing, unlock, and signaling | `routers/pairing.py` | Setup and unlock, the secure pairing handshake, local pair information, live pairing, and the setup QR code |
| WebRTC and media | `routers/webrtc.py` | Live sessions, microphone and screen sharing, video-file playback, and remote input |
| Messaging connectors | `routers/messaging.py` | Telegram, Signal, and WhatsApp control |
| Models and speech | `routers/models.py` | The model library, speech models, and WebRTC configuration parsing |
| Companion services | `routers/services.py` | The AI Agent worker, the page service, the Tunnelmole public link, status, and shutdown |
| AutoYou Cloud | `routers/cloud.py` | Cloud Pair registration, device approval, and guest access |
| MCP bridge | `routers/mcp.py` | Routes used by MCP clients |
| Moderation | `routers/moderation.py` | Reports and blocks |
| Peer Link | `routers/peer_rendezvous.py` | Invite page and rendezvous status |
| Website gateway | `routers/website_gateway.py` | Agent websites served on the admin origin, behind the admin sign-in. See [Website Gateway & Page Service](/api-reference/website-gateway). |

### Password and security settings

These routes need an admin sign-in, and a remote browser cannot use them.

| Route | Purpose |
| :--- | :--- |
| `POST /api/admin/password`, `POST /api/admin/password/generate` | Change the server password, or generate a strong one |
| `POST /api/admin/security/mode` | Set the security mode: `normal`, `secure`, `secure_professional`, or `secure_professional_maximus` |
| `POST /api/admin/security/tier` | Set the pairing tier: Quick (`B`) or Enhanced (`A`) |
| `POST /api/admin/security/storage/rotate` | Rotate the storage key (Maximus only) |
| `POST /api/admin/config` | Update configuration. Some sections are protected from remote browsers. |

### Authenticator

`POST /admin/security/totp/generate`, `show`, `import`, and `delete`, `GET /admin/security/totp/current-code`, and `POST /api/native/security/totp/setup`, `confirm`, `import`, and `delete` manage the shared authenticator.

### Chat

`POST /api/chat` sends a turn to AutoYou AI. `GET /api/chat/sessions` and `GET /api/chat/session` read conversation history, and `POST /api/chat/session/reply` sends your own words to a connected device. These are explained in the [server overview](../technical/server.md).

### Agents

`GET /api/agents/manage`, `POST /api/agents/install`, `POST /api/agents/uninstall`, and `POST /api/agents/frontend` manage installed agents and their website frontends. The workbench routes under `/api/agents/workbench/{agent_name}` cover testing, cloning, publishing, and discarding an agent draft.

### Status

`GET /api/status` is a basic status check, `GET /api/connection/status` returns a connection-helper snapshot, and `GET /api/datachannel-status` reports DataChannel state. Status payloads describe this computer, so a direct caller from the network must be signed in to read them.
