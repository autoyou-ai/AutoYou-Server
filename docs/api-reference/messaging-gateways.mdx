# Messaging Gateways APIs

AutoYou Server bridges external messaging channels directly into the agent runtime, allowing operators and approved contacts to interact with agents via WhatsApp, Signal, and Telegram.

---

## WhatsApp Gateway

### `GET /api/whatsapp/status`
Returns the status of the background Node.js WhatsApp Puppeteer worker.

#### Response (`200 OK`)
```json
{
  "running": true,
  "state": "CONNECTED", // "INITIALIZING" | "SCAN_QR_CODE" | "CONNECTED" | "DISCONNECTED"
  "phone_number": "+14155552671",
  "battery_level": 94
}
```

### `GET /api/whatsapp/qr`
Retrieves the raw QR code string or SVG for device pairing.

#### Response (`200 OK`)
```json
{
  "qr_string": "2@b9f1a23c4d5e...==,ABCD,1",
  "qr_svg": "<svg xmlns='http://www.w3.org/2000/svg'..."
}
```

### `POST /api/whatsapp/send`
Dispatches an outbound text message to a WhatsApp recipient.

#### Request Payload
```json
{
  "recipient": "+14155552671",
  "message": "Hello from AutoYou Assistant!"
}
```

### `POST /api/whatsapp/reset`
Clears stored browser session caches and forces a clean Puppeteer re-initialization.

## Signal Gateway

### `GET /api/signal/status`
Returns the operational state of the local `signal-cli` daemon.

#### Response (`200 OK`)
```json
{
  "running": true,
  "registered_number": "+14155552671",
  "device_id": 2
}
```

### `GET /api/signal/qr`
Generates a linking URI (`tsdevice:/?uuid=...`) formatted as a QR code image to link the server as a companion Signal device.

### `POST /api/signal/send`
Sends an end-to-end encrypted message over the Signal protocol.

#### Request Payload
```json
{
  "recipient": "+14155552671",
  "message": "Backup completed successfully."
}
```

## Telegram Gateway (Bot & User Client)

### `GET /api/telegram/senders`
Returns the approval queue of unverified Telegram users who have initiated conversations with the bot.

#### Response (`200 OK`)
```json
{
  "pending_senders": [
    {
      "user_id": 84210948,
      "username": "johndoe",
      "first_name": "John",
      "initial_message": "Hello, can you help me?",
      "timestamp": 1727999300000
    }
  ]
}
```

### `POST /api/telegram/senders/approve`
Approves a pending sender, allowing AutoYou agents to process their requests.

#### Request Payload
```json
{
  "user_id": 84210948,
  "assigned_profile": "Standard Agent"
}
```

### `POST /api/telegram-user/2fa`
Submits the two-step verification password when authenticating a full Telegram User client.

#### Request Payload
```json
{
  "password": "MyTelegramCloudPassword"
}
```
