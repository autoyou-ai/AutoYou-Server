# MCP Bridge API

The bridge is a narrow REST interface on the admin app (port `8001`). An MCP adapter, which is a separate process, calls it on behalf of MCP clients. The server does not speak the Model Context Protocol itself: it exposes no JSON-RPC endpoint, and the adapter is not part of this repository. How to enable and authenticate the bridge, and how to set up the adapter, is in [MCP Integration](/guides/mcp-integration).

Errors use the shape in the [API overview](/api-reference/overview).

---

## Authentication

Every route needs the MCP API token (`mcp.api_token` or `AUTOYOU_MCP_API_TOKEN`), sent as `Authorization: Bearer <token>` or in the `x-autoyou-mcp-token` header. Without a configured token, requests are accepted only when both the server's bind and the caller are on loopback. The bridge answers `403` when it is disabled.

## Routes

### `GET /api/v1/mcp/status`

Returns the bridge and server state:

| Field | Meaning |
| :--- | :--- |
| `status` | `running` |
| `version` | `full-server` |
| `connected_sessions`, `sessions` | The number and ids of connected WebRTC sessions |
| `ai_provider`, `ai_model` | The active provider and model |
| `security_mode`, `security_tier` | The server's security mode and pairing tier |
| `mcp_enabled` | Whether the bridge is enabled |

### `GET /api/v1/mcp/sessions`

Connected WebRTC sessions, keyed by session id. Each entry has `transport`, `connected`, `owner_key`, and `canonical_session_id`.

### `POST /api/v1/mcp/send/{session_id}`

Sends a text message to a connected device. Body: `{"text": "...", "metadata": {}, "user_id": ""}`. `text` is required and at most 16,000 characters. The sender identity is the server's own; `user_id` is not honored. Response: `{"sent": true, "session_id": "...", "source": "autoyou-mcp"}`.

### `POST /api/v1/mcp/pair`

Submits a pairing message to the pairing router. Body: `text` (up to 512,000 characters), `platform` (default `chatgpt`), and `sender_id`. The text must be a pairing command (`/pair`, `/otp_pair`, `/pair_hello`, `/autopair_hello`, `/autopair`, `/autopair_candidates`) or a pairing fragment; anything else returns `400` with `unsupported_pairing_message`.

### `POST /api/v1/mcp/chat`

Sends a chat turn to AutoYou AI. Body: either `message` (up to 16,000 characters) or OpenAI-style `messages`, plus optional `model`, `session_id`, `user`, `context` (attachments), and `metadata`.
