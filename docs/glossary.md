# Glossary

Essential AutoYou terminology explained.

---

## A

### Agent
A specialized AI personality optimized for specific tasks (coding, notes, tasks, etc). The root agent routes between specialists.

### API Key
Authentication token for cloud AI services (Gemini, OpenAI, Claude). Kept secure on your server.

### App Browser
Feature that displays your computer's local web services (localhost apps) on your phone.

### Autopair
One-shot pairing method using messaging apps (Telegram, WhatsApp, Signal).

### AutoYou Cloud
Optional bootstrap service that helps devices find each other. Does NOT store your data or AI.

---

## B

### Browser Forwarding
See **App Browser**.

---

## C

### Chat
Text-based conversation with your AI. Supports multi-turn, memory, and context.

### Cloud AI
AI model hosted externally (Gemini, OpenAI, Claude). Requires internet and API key.

### Cloud-Pair
Device pairing using AutoYou Cloud with Google OAuth. Enables auto-reconnection and remote access.

### Coding Agent
Specialized agent for programming tasks: debugging, code review, generation.

---

## D

### Direct Link
An encrypted connection between your client and your AutoYou server.

### Dynamically Loaded Agent
An AutoYou agent that can be added without changing the main app.

---

## F

### App Server
The local server that powers AutoYou on your machine.

---

## G

### Gemini
Google's AI model. Cloud-based, powerful, available via API.

---

## H

### Hybrid AI
Combining local LLM with cloud fallback. Uses Ollama first, falls back to cloud if needed.

---

## I

### Internet Agent
Specialized agent for web search and browsing tasks when enabled.

---

## L

### LAN
Local Area Network. Your home WiFi or office network.

### Local AI
AI models running on your computer (Ollama). Privacy depends on your local logs, model configuration, and any services you enable.

### Localhost
Your computer's internal address. Used for local services like development servers.

---

## M

### Memory
Persistent storage of context: chat, notes, preferences, history.

### Mistral
Open-source 7B LLM model. Good for local use (fast, small).

---

## N

### Notes Agent
Specialized agent for saving, organizing, and retrieving notes.

---

## O

### OAuth
Open authentication standard. Used for Google Sign-In.

### Ollama
Local LLM runner. Downloads and runs models on your computer.

### OTP
One-Time Password. Code for manual pairing (6-8 digits).

---

## P

### Pairing
Process of connecting a phone/device to your AutoYou Server.

### Pairing Code
Code (displayed on server) for manual pairing with phone.

---

## R

### Root Agent
Main AI that understands intent and routes to specialized agents.

---

## S

### Secure Mode
Medium security level using password protection for pairing.

### Secure Professional
Highest security using password + an authenticator app code for pairing.

### Secure Professional Maximus
Secure Professional pairing plus stronger protection for AutoYou-managed data saved on the server computer.

### Server
AutoYou application running on your computer. The "brain."

### Session
Conversation or connection instance. Can be saved and resumed.

### SQLite
Lightweight database used for local storage of notes and memory.

### STT
Speech-to-Text. Converts voice to text. Can be local or cloud.

---

## T

### Tasks Agent
Specialized agent for project planning, to-do lists, goal tracking.

### Authenticator App Code
Six-digit 2FA code generated by an authenticator app.

### TTS
Text-to-Speech. Converts text to voice. Can be local or cloud.

---

## V

### Voice Mode
Conversation using audio instead of text. Includes STT and TTS.

---

## W

### Website Agent
Specialized agent for creating browser pages for AutoYou agents.
