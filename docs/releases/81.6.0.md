# AutoYou Server 81.6.0

Release status: source release, tag `81.6.0`, published by the
[Release workflow](../../.github/workflows/release.yml).

## What is in this release

This is a source release. The GitHub release attaches the sanitized public
source archive (`.tar.gz` and `.zip`), the generated SBOM and NOTICE bundles,
and a `SHA256SUMS.txt` file. No compiled server binaries are attached. A
platform build is published only after its build, legal, and runtime gates pass.

To run it, follow the [quick start](../../README.md#quick-start):

```bash
git clone --branch 81.6.0 https://github.com/autoyou-ai/AutoYou-Server.git
cd AutoYou-Server
./run_autoyou.sh --profile base
```

On Windows, run `.\run_autoyou.bat --profile base`.

## Highlights

### Assistant Agent and Skin Packs (`.ayskin`)

- Native Assistant Agent support with custom skin packs (`.ayskin`), visual web
  designer, portable interactive worlds (`shared/assistant_world.py`), trained wake-word exchange (`shared/wake_word.py`), and server synchronization (`shared/assistant_skin.py`).
- Smaller local model fallback when Ollama cannot load the primary model,
  automatic turn continuation, English and Spanish conversational rules,
  `calculate` tool, outbox delivery, and warm start.

### Page Agent and Offline Games (`.aygame`)

- Page Agent direct-first CDN video and reel playback (`referrerpolicy=no-referrer`),
  computer stream relay fallback, and optional inline third-party/Instagram
  embed controls (`autoyou_agents/page_agent/`).
- Bundled offline HTML5 games (`neon-horizon.aygame`) with mandatory
  `AutoYouGame.quit()` host bridge and external popup routing.

### Networking, Desktop Wake, and Security

- Native Wi-Fi/LAN prioritization, macOS hardware port mapping, Linux interface
  classification, WSL host interop, streaming large chat attachments up to 5 GB (`shared/chat_file_transfer.py`), and remote-desktop
  display wake / `secure-desktop` CLI helper.
- Updated dependencies (`joserfc` 1.7.6, `pyasn1` 0.6.5, `follow-redirects`
  1.16.2, `datasets` >=5.1.0,<6) and unified License Version 1.5 (November 4,
  2026) with defensive patent termination and third-party beneficiary
  indemnification for OpenStorey LLC and the AutoYou Owner Board.
  Remaining advisory decisions are listed in
  [the dependency audit](../security/dependency-audit.md).

### Build and release

- Tagged releases are produced by the Release workflow, and
  `scripts/check_release_version.py` keeps every version mention (launchers,
  installer, macOS Info.plist, Windows manifests, server READMEs) in step with
  `VERSION`.
