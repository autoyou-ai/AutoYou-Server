# AutoYou Server 81.0.1

Release status: candidate for the 81.0.1 release line.

Status update: this candidate is superseded by 81.0.2 before completion of the
release gates. No 81.0.1 tag or GitHub release was published.

## Scope

This candidate is based on the `main` commit `1e1c7c8` and the synchronized
AutoYou checkout at root commit `023e2c519`.

The release includes the current cloud stream reliability and security work:

- Server event streams retire stale connections cleanly and keep each device's
  undelivered relay queue attached to the active stream.
- Server and client cloud event streams back off after failures and stable
  connections are required before the retry delay resets.
- Redis subscription recovery reconnects with bounded backoff instead of
  spinning or silently losing the stream.
- The VM1 deployment health checks use the current HTTPS and low-cost probe
  configuration.
- Local Pair remains loopback-first and the production route contract keeps
  protected admin and AI ports off public tunnel origins.

## Release note

The canonical version is `81.0.1`. The server repository has no prior release
tag for this version at the time this note was written. Create and push an
annotated `81.0.1` tag only after the build, legal, and runtime gates pass.

The public repository release must link to the exact server commit and retain
the generated checksums and legal bundle evidence. A local build or a Git tag
does not by itself prove that a GitHub release or a Partner Center submission
was published.
