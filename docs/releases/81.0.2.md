# AutoYou Server 81.0.2

Release status: published on 2026-10-09 as a source release, tag `81.0.2`.
It supersedes the unpublished 81.0.1 candidate.

## What is in this release

This is a source release. The GitHub release attaches the source archive and its
SHA-256 checksum. No compiled server binaries are attached. A platform build is
published only after its build, legal, and runtime gates pass.

To run it, follow the [quick start](../../README.md#quick-start):

```bash
git clone --branch 81.0.2 https://github.com/autoyou-ai/AutoYou-Server.git
cd AutoYou-Server
./run_autoyou.sh --profile base
```

On Windows, run `.\run_autoyou.bat --profile base`.

## Changes since 81.0.0

### Security

- Keychain asks once for each saved item per process. A refusal is remembered
  briefly instead of being asked again by every internal retry.
- Home-network websites use device passes. Local Pair uses pinned direct HTTPS.
- Passwords stay off the LAN. Cloud Pair keys are pinned. `run_autoyou`
  installs are hardened.
- Remote admin permissions for WSL, Docker, and LAN connections over HTTPS are
  available as an opt-in setting. Proxied private peers are recognised only when
  network admin permissions are on.

### Agents and Agent Apps

- The Agent Apps store replaces the Agent Websites directory page. On mobile,
  the selected app's dock collapses and its handle moves to the swipe target.
- External agent website runtimes can be managed from the server.
- Your own agents go in the git-ignored `autoyou_agents/private/` directory.
  The server discovers agents that this repository does not ship instead of
  naming them, and it reads nothing outside its own checkout.
- Shortcuts act or defer and never ask. Chat context is carried into specialist
  agents and attached to every Notes and Page dispatch. A link is no longer
  treated as a web request.
- Notes shows voice-note and photo badges. The Persona journal plays
  attachments inline, with Range support.
- macOS builds leave out the optional Model Picker agent and its llmfit helper.

### Calls and media

- Remote Desktop can control the screen. Page and phone routing profiles are
  added.
- The Computer's display picture is sent on connect and to every live client.
- Video recordings include call audio.
- Outgoing H.264 no longer requires x264. The server uses the first encoder
  that opens: libx264, then OpenH264, then Windows Media Foundation
  (`AUTOYOU_H264_ENCODER` names one to try first). Video recording uses the
  same encoder.
- `scripts/build_codec_clean_av.py` builds a PyAV 16.1.0 wheel against an LGPL
  FFmpeg build without x264 or x265, pinned by SHA-256. Windows backend builds
  can use it with `build-backend.ps1 -AvWheel`.

### Reliability and build

- The server backs off when the cloud event stream keeps dropping.
- Admin page button clicks are no longer lost to background renders.
- The packaged runtime plan includes package initializers. Docker images keep
  private agents and local-only trees out.
