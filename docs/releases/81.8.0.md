# AutoYou Server 81.8.0

Source release for tag `81.8.0`.

## What is in this release

This is a source release. The GitHub release attaches the sanitized public
source archive (`.tar.gz` and `.zip`), the generated SBOM and NOTICE bundles,
and a `SHA256SUMS.txt` file. No compiled server binaries are attached. A
platform build is published only after its build, legal, and runtime gates pass.

To run it, follow the [quick start](https://github.com/autoyou-ai/AutoYou-Server/tree/81.8.0#quick-start):

```bash
git clone --branch 81.8.0 https://github.com/autoyou-ai/AutoYou-Server.git
cd AutoYou-Server
./run_autoyou.sh --profile base
```

On Windows, run `.\run_autoyou.bat --profile base`.

## Highlights

- **Windows stability & packaging**: Moves the LiteLLM/tiktoken BPE rank cache to a writable per-user directory with automatic LF repair (resolving read-only `WindowsApps` Store failures), eliminates WebView2 pane-animation freezes and duplicate process bloat, fixes `OfflineGameWindow` launch initialization, and eliminates unobserved socket connect exceptions.
- **Desktop UX & onboarding parity**: Adds a dismissible first-launch Setup Guide, interactive Windows System Permissions checklist (`ms-settings:` & `firewall.cpl`), contextual Chat toolbar, Admin UI hash deep-linking (`#security`, `#pairing-2fa`, `#ai-provider`, `#ai-models`, `#local-network`), and streamlined `qwen3.5:4b` starter model recommendations.
- **Native Windows computer-use**: Enumerates windows via Win32 `EnumWindows` and passes UTF-16LE `-EncodedCommand` scripts for reliable Windows UI Automation snapshots and actions.
- **Media generation, content library & personal harness**: Upgrades the media factory and shared content library workflows with verified personal harness regression coverage and Google ADK 2.14.0 / MCP 2.3.0 runtime alignment.
