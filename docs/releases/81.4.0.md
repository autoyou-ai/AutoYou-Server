# AutoYou Server 81.4.0

Release status: source release, tag `81.4.0`, published by the
[Release workflow](../../.github/workflows/release.yml).

## What is in this release

This is a source release. The GitHub release attaches the sanitized public
source archive (`.tar.gz` and `.zip`), the generated SBOM and NOTICE bundles,
and a `SHA256SUMS.txt` file. No compiled server binaries are attached. A
platform build is published only after its build, legal, and runtime gates pass.

To run it, follow the [quick start](../../README.md#quick-start):

```bash
git clone --branch 81.4.0 https://github.com/autoyou-ai/AutoYou-Server.git
cd AutoYou-Server
./run_autoyou.sh --profile base
```

On Windows, run `.\run_autoyou.bat --profile base`.

## Highlights

### Assistant mode

- A personal wake word gates background transcription. Phones, desktops and
  the Pi can detect the wake word on the device; iPhones hear it on the device
  too.
- Settings are localhost-only, Assistant mode can be chosen per call, and
  wake-word setup is guided.
- Device wakes are reserved before upload, wake ownership is shared with the
  admin browser, stale transcriptions are invalidated, and streamed training
  updates are broadcast.

### Games and Agent Apps

- Neon Horizon gains a settings panel (music, tilt controls, high-score reset),
  a score- and obstacle-aware soundtrack, power-ups, missions and new graphics.
- Offline game packages, a game catalog and observe mode.
- Pi coding agent, Antigravity bridge, Codex question handling and Prompt
  Builder controls.

### Voice and media

- Owner voice cloning uses Chatterbox in a separate runtime on patched
  Transformers and Diffusers.
- GPU-aware PyTorch wheel selection, FFmpeg runtime detection, native music
  uploads, offline media downloads, and Wan2GP streaming memory profiles.

### Security

- Shared OTP guessing budget, locally generated QR codes, sandboxed artifacts.
- Error responses carry a reference instead of exception text; untrusted text
  is kept out of HTML, navigation and ID sinks; link hosts match exactly.
- Updated server dependencies, Node helper parsers and upload handling.
  Remaining advisory decisions are listed in
  [the dependency audit](../security/dependency-audit.md).

### Build and release

- GitHub Actions run only when relevant files change, cancel superseded runs,
  and Dependabot PRs get their SBOM and NOTICE bundles regenerated
  automatically.
- Tagged releases are produced by the Release workflow, and
  `scripts/check_release_version.py` keeps every version mention (launchers,
  installer, macOS Info.plist, Windows manifests, server READMEs) in step with
  `VERSION`.
