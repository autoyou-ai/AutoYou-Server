# AutoYou Server 81.7.0

Source release for tag `81.7.0`.

## What is in this release

This is a source release. The GitHub release attaches the sanitized public
source archive (`.tar.gz` and `.zip`), the generated SBOM and NOTICE bundles,
and a `SHA256SUMS.txt` file. No compiled server binaries are attached. A
platform build is published only after its build, legal, and runtime gates pass.

To run it, follow the [quick start](https://github.com/autoyou-ai/AutoYou-Server/tree/81.7.0#quick-start):

```bash
git clone --branch 81.7.0 https://github.com/autoyou-ai/AutoYou-Server.git
cd AutoYou-Server
./run_autoyou.sh --profile base
```

On Windows, run `.\run_autoyou.bat --profile base`.

## Highlights

- **Remote Desktop Meet** separates host input control from the call. Live text appears in each participant's card, and sent messages stay available in Activity.
- **Screen sharing and media** have lower latency in fullscreen and Meet. Data channel pacing and request cancellation improve large transfers and offline library browsing.
- **Messaging and pairing** let administrators approve recent Telegram, WhatsApp, and Signal contacts. OTP and Auto Pair replies include clickable links. Authenticator verification uses UTC and offers clock-sync guidance on rejection.
- **Agent libraries** report total counts across paginated results, including notes, pages, and personae.
- **Runtime fixes** restore ADK chat and Ollama media compatibility. dnspython 2.9.2 and Soup Sieve 4.0 address their published security advisories.
