# Monetization & Utility Agents

These agents support creator monetization, rewarded ads, user donations, educational walkthroughs, and hosted gaming.

---

## 1. `ads_watching_agent`
- **Location**: `autoyou_agents/ads_watching_agent/`
- **Role**: Coordinates rewarded video and ad viewing workflows for free-tier users, verifying ad completion callbacks and crediting tokens to the user account.
- **Frontend**: Available at `http://127.0.0.1:8067/agent/ads_watching_agent/`.
- **Key Tools**:
  - `request_rewarded_ad()`: Fetches an eligible ad payload from approved publisher networks.
  - `verify_ad_completion(transaction_id: str)`: Confirms viewing verification token.

---

## 2. `earnings_agent`
- **Location**: `autoyou_agents/earnings_agent/`
- **Role**: Financial ledger and monetization dashboard for host operators who provide compute or host community agent services.
- **Frontend**: Available at `http://127.0.0.1:8067/agent/earnings_agent/`.
- **Key Tools**:
  - `get_balance_summary()`: Returns accumulated compute credits and fiat balances.
  - `request_payout(payout_method: str)`: Initiates a payout transfer.

---

## 3. `donation_agent`
- **Location**: `autoyou_agents/donation_agent/`
- **Role**: Creator tipping and contribution processor supporting Stripe Checkout and community funding links.
- **Frontend**: Available at `http://127.0.0.1:8067/agent/donation_agent/`.
- **Key Tools**:
  - `create_checkout_session(amount_usd: float)`: Generates a Stripe Checkout session URL.
  - `verify_donation(session_id: str)`: Validates receipt of a creator tip.

---

## 4. `education_agent`
- **Location**: `autoyou_agents/education_agent/`
- **Role**: Interactive onboarding and documentation tutor. Answers developer questions about AutoYou APIs, teaches how to write custom agents, and guides users through system settings.
- **Frontend**: Available at `http://127.0.0.1:8067/agent/education_agent/`.
- **Key Tools**:
  - `explain_concept(concept_name: str)`: Delivers an interactive educational walkthrough.
  - `quiz_user(topic: str)`: Evaluates user comprehension.

---

## 5. `game_agent`
- **Location**: `autoyou_agents/game_agent/`
- **Role**: Hosts lightweight interactive HTML5 games and streaming experiences, managing high-score leaderboards and game streaming sessions over WebRTC.
- **Frontend**: Available at `http://127.0.0.1:8067/agent/game_agent/`.
- **Key Tools**:
  - `get_high_scores(game_id: str)`: Queries the local high-score database (`login_ui_state.db`).
  - `record_score(game_id: str, score: int)`: Saves verified player scores.
