# Web & Automation Agents

Web & Automation agents deliver sandboxed headless browser automation, client browser window orchestration, and fast network search and content extraction.

---

## 1. `browser_agent`

- **Location**: `autoyou_agents/browser_agent/`
- **Role**: Headless and headful real-browser automation engine. Supports Chromium via Playwright, as well as native WKWebView on macOS for sandboxed App Store compliance.
- **Security Safeguards**:
  - Private network filtering and DNS pinning to prevent Server-Side Request Forgery (SSRF) against internal services.
  - Parent-owned pipe control instead of vulnerable remote debugging listening ports.
  - Automatic screenshot capture, DOM traversal, and action recording.
- **Key Tools**:
  - `navigate_url(url: str)`: Loads a webpage safely, checking URL safety against the internal blocklist.
  - `click_element(selector: str)`: Simulates user click on DOM buttons, links, or inputs.
  - `fill_form(selector: str, text: str)`: Injects text into form fields.
  - `take_page_screenshot()`: Captures full-page or viewport visual rendering.
  - `extract_dom_text(selector: str = "body")`: Extracts clean readable text from DOM elements.

---

## 2. `client_browser_control_agent`

- **Location**: `autoyou_agents/client_browser_control_agent/`
- **Role**: Allows the server to orchestrate web browsing directly within a connected client device's native browser window (e.g. on AutoYou Connect on Windows/macOS or an iPad/Android client).
- **Key Tools**:
  - `open_client_tab(url: str)`: Requests that the client device open a new browser tab with the specified URL.
  - `close_client_tab(tab_id: str)`: Closes an active client browser tab.
  - `get_client_browser_capabilities()`: Queries supported browser control features on the client platform.

---

## 3. `internet_agent`

- **Location**: `autoyou_agents/internet_agent/`
- **Role**: Provides fast, safe internet search, link inspection, and article summarization without the overhead of launching a full headless browser.
- **Key Tools**:
  - `search_web(query: str, num_results: int = 5)`: Executes web queries against configured search providers (DuckDuckGo, SearXNG, or Google Search API).
  - `fetch_page_content(url: str)`: Downloads and parses raw HTML into clean Markdown text, stripping ads and tracking scripts.
  - `validate_url_safety(url: str)`: Validates that a destination IP is public and does not target RFC 1918 private subnets.
