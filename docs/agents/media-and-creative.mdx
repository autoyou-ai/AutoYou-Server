# Media & Creative Agents

Media & Creative agents manage local audio playback, sound device routing, AI image and media synthesis, rich Markdown note taking, and public feed publishing.

---

## 1. `audio_agent`

- **Location**: `autoyou_agents/audio_agent/`
- **Role**: Comprehensive music player, playlist editor, and audio library manager. Streams audio over WebRTC data channels or HTTP Range (206) requests to connected native clients.
- **Frontend**: Full-featured web app hosted at `http://127.0.0.1:8067/agent/audio_agent/`.
- **Key Features**:
  - Incremental library pagination via `GET /api/library` with scroll position preservation.
  - Integration with AmplitudeJS for background playback handoff and persistent volume management.
  - Playlist creation, metadata tagging, and full library search.
- **Key Tools**:
  - `play_track(track_id: str)`: Initiates playback on the server host or forwards stream to an active client device.
  - `search_audio_library(query: str)`: Searches artist, album, genre, and track metadata across local media directories.
  - `create_playlist(name: str, tracks: list)`: Generates and saves a new named playlist in the media database.
  - `get_audio_devices()`: Queries host audio input (microphone) and output (speaker) devices.

## 2. `media_generation_agent`

- **Location**: `autoyou_agents/media_generation_agent/`
- **Role**: Coordinates local and cloud text-to-image models (Stable Diffusion, FLUX), video clip generation, and audio sound effect synthesis.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/media_generation_agent/`.
- **Key Tools**:
  - `generate_image(prompt: str, aspect_ratio: str = "1:1")`: Synthesizes an image from a natural language prompt using configured image generation backends.
  - `inspect_generated_media()`: Returns recently generated visual assets with metadata, dimensions, and file references.
  - `export_media_artifact(artifact_id: str, format: str = "png")`: Transcodes or exports media artifacts into standard distribution formats.

---

## 3. `notes_agent`

- **Location**: `autoyou_agents/notes_agent/`
- **Role**: Rich Markdown note-taking and personal knowledge base with full-text search, tag indexing, and media attachment support.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/notes_agent/`.
- **Storage**: Dedicated SQLite database inside the mutable data root (`autoyou_notes_agent/notes.db`).
- **Key Tools**:
  - `create_note(title: str, content: str, tags: list = None)`: Creates a new Markdown note with optional categorization tags.
  - `search_notes(query: str)`: Performs full-text keyword and tag searches across all stored notes.
  - `get_note(note_id: str)`: Reads full note content, revision history, and linked metadata.
  - `update_note(note_id: str, content: str, tags: list = None)`: Updates note content atomically.
  - `delete_note(note_id: str)`: Soft-deletes or purges an existing note.
  - `attach_media_to_note(note_id: str, media_id: str)`: Associates an image, audio clip, or document with a note.

---

## 4. `page_agent`

- **Location**: `autoyou_agents/page_agent/`
- **Role**: Backs the **AutoYou Page** social community feed and web publication engine (`page_feed.db`). Publishes articles, media cards, user updates, and structured agent outputs to shareable client views.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/page_agent/`.
- **Storage**: `page_feed.db` under the local server state directory.
- **Key Tools**:
  - `publish_post(title: str, content: str, media_urls: list = None)`: Authors and publishes a new post in the local social feed.
  - `search_feed(query: str)`: Searches published feed posts by keyword, date, or author identity.
  - `delete_post(post_id: str)`: Deletes an authored post and its associated feed cache entries.
  - `get_feed_status()`: Queries total post count, engagement statistics, and pending drafts.
