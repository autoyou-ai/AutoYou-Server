# System & Administration Agents

System & Administration agents govern server runtime health, service orchestration, automated backups, external domain hosting, and host-level OS security policies on Windows and macOS.

---

## 1. `admin_agent`

- **Location**: `autoyou_agents/admin_agent/`
- **Role**: Primary administrative controller responsible for inspecting server health, reading system diagnostics, managing configuration, coordinating service lifecycles, and verifying security permissions.
- **Frontend**: Integrated directly into the Admin Console at `/admin`.
- **Security Scope**: Requires `System Admin` security profile privileges and TOTP session elevation.
- **Key Tools**:
  - `get_system_health()`: Returns real-time host metrics including CPU utilization, RAM usage, storage availability, and background process status.
  - `restart_service(service_name: str)`: Requests a graceful restart of a managed background subprocess or gateway listener.
  - `scan_system_logs(lines: int = 50)`: Retrieves recent server runtime execution logs with automatic credential and personal identifier redaction.
  - `check_admin_session()`: Verifies if the active administrative session token is valid and unexpired.
  - `verify_admin_totp(totp_code: str)`: Validates a 6-digit TOTP code against the encrypted keystore to elevate privileges.
  - `revoke_admin_session()`: Invalidates the current administrative session immediately.

---

## 2. `backup_agent`

- **Location**: `autoyou_agents/backup_agent/`
- **Role**: Coordinates automated database backups, filesystem snapshots, encrypted state export, and cross-device recovery of user data, sessions, and configuration stores.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/backup_agent/`.
- **Key Tools**:
  - `create_backup(include_media: bool = False)`: Creates an encrypted timestamped snapshot archive of `sessions.db`, `page_feed.db`, `login_ui_state.db`, and configuration vaults.
  - `list_backups()`: Enumerates previous backup archives with timestamps, size, and SHA-256 integrity checksums.
  - `restore_backup(backup_id: str)`: Restores server state from an authenticated snapshot, validating schema versions before applying mutations.
  - `verify_backup_integrity(backup_id: str)`: Audits snapshot cryptographic signatures and database consistency.

---

## 3. `hosting_agent`

- **Location**: `autoyou_agents/hosting_agent/`
- **Role**: Publishes local agent websites, portals, and media endpoints to the public internet using Tunnelmole tunnels or custom domain reverse proxies with automated SSL certificates.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/hosting_agent/`.
- **Key Tools**:
  - `publish_site(agent_name: str)`: Generates a public HTTPS URL forwarding securely to the specified agent's local web frontend.
  - `revoke_public_access(agent_name: str)`: Disables the public tunnel immediately and clears active domain bindings.
  - `get_hosting_status()`: Queries active public tunnels, connection latency, bandwidth consumption, and SSL certificate expiration.
  - `configure_custom_domain(domain_name: str, target_port: int)`: Provisions DNS and SSL routing for operator-owned custom domains.

## 4. `win_security_agent`

- **Location**: `autoyou_agents/win_security_agent/`
- **Role**: Windows-specific host security agent that monitors host firewall rules, Windows Defender status, loopback listener boundaries, UAC elevations, and Authenticode binary signatures.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/win_security_agent/`.
- **Key Tools**:
  - `audit_windows_defender()`: Queries Windows Security Center via WMI to verify real-time protection and antivirus definitions.
  - `inspect_open_listeners()`: Audits active TCP/UDP ports to ensure administrative endpoints (`8123`, `8067`, `8068`) remain bound strictly to loopback (`127.0.0.1`).
  - `audit_firewall_rules()`: Inspects Windows Filtering Platform (WFP) rules and WinDivert bindings.
  - `check_privilege_level()`: Verifies whether the server process is running with standard mediumIL or elevated administrator rights.

---

## 5. `mac_security_agent`

- **Location**: `autoyou_agents/mac_security_agent/`
- **Role**: macOS-specific security agent that monitors App Sandbox entitlements, Keychain access, Gatekeeper notarization, and macOS privacy permissions (Camera, Microphone, Accessibility, Screen Recording).
- **Backend Listener**: Operates a dedicated internal loopback backend on port **8101** so it does not interfere with the primary browser proxy on port 8067.
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/mac_security_agent/`.
- **Key Tools**:
  - `audit_tcc_permissions()`: Audits Transparency, Consent, and Control (TCC) grant states for camera, microphone, screen capture, and accessibility.
  - `verify_code_signature()`: Validates Apple Developer code signatures and hardened runtime flags against the macOS Security framework.
  - `inspect_open_listeners()`: Confirms administrative listeners remain locked to local loopback.
  - `audit_keychain_status()`: Validates that cryptographic secrets are securely anchored in the macOS Keychain Services API.
