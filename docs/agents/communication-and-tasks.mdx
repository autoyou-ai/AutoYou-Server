# Communication & Task Agents

Communication & Task agents manage cross-platform alert dispatches, background job scheduling, reminder alarms, and recurring workflow automation.

---

## 1. `notify_agent`

- **Location**: `autoyou_agents/notify_agent/`
- **Role**: Dispatches real-time alerts and audible chimes across multiple client surfaces (OS desktop toasts, mobile push notifications, and voice call announcements).
- **Frontend**: Available via the internal agent proxy at `http://127.0.0.1:8067/agent/notify_agent/`.
- **Key Tools**:
  - `send_desktop_notification(title: str, message: str, urgency: str = "normal")`: Fires an OS desktop toast alert on the host machine.
  - `send_push_notification(device_id: str, title: str, body: str)`: Sends a push alert via Apple APNs or Google FCM to paired mobile devices.
  - `play_alert_chime(chime_type: str = "bell")`: Triggers an audible alert through the server audio output or active WebRTC session.
  - `get_notification_history(limit: int = 50)`: Returns recent delivered notifications and delivery receipt statuses.

---

## 2. `tasks_agent`

- **Location**: `autoyou_agents/tasks_agent/`
- **Role**: Intelligent personal task manager and job scheduler. Tracks to-do lists, schedules recurring cron triggers, and monitors project deadlines and reminders.
- **Frontend**: Integrated directly with the task scheduler panel in the Admin UI.
- **Key Tools**:
  - `add_task(title: str, due_date: str = None, priority: str = "medium")`: Adds a task to the queue with priority and optional deadline.
  - `list_tasks(status: str = "pending")`: Lists incomplete tasks sorted by due date and priority level.
  - `complete_task(task_id: str)`: Marks an existing task as completed.
  - `schedule_reminder(reminder_text: str, trigger_time_utc: str)`: Registers a one-time reminder alarm.
  - `schedule_cron_job(cron_expression: str, prompt_to_run: str)`: Registers a recurring agent execution job triggered via standard 5-part cron syntax.
