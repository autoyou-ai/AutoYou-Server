# Support

- For a reproducible defect, use the bug-report form and remove secrets, logs with personal data, and credentials.
- For a proposal or product question, use the feature-request form or an existing issue.
- For a security vulnerability, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.
- For license scope, read [LICENSE](LICENSE) before contacting a repository maintainer through GitHub.

This repository does not promise response times, hosted-service access, or support for unofficial builds.
