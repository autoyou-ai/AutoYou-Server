# Support

For setup and product help, use [AutoYou support](https://www.autoyou.me/support/).
For discussion and extension development, use
[the community](https://www.autoyou.me/community/).

Use this repository's issue forms for reproducible server defects and feature
proposals. Include the version or commit, operating system, selected profile,
whether the build is unofficial or modified, reproduction steps, and a small
sanitized log excerpt. Remove secrets, personal data, local account names,
public access links, and device identifiers.

Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
Do not attach a live configuration, credentials, a database, or an unreviewed
diagnostic archive to an issue.

Start the server with [the source instructions](README.md#run-from-source) or
compile it using the platform guides. Separately distributed client
applications require a running server and do not include a hosted server
entitlement merely because they are installed.

Community help is provided as available. A contribution, sponsorship, app
installation, or unofficial build does not create a support SLA. Contracted
support and Institutional Use are covered by a separate
[Enterprise agreement](https://www.autoyou.me/enterprise/).
