# Security Policy

Report security issues to `security@autoyou.me`.

Please include the affected version, artifact, operating system, reproduction steps, and expected impact. Avoid sending secrets, private keys, unrelated personal data, or third-party conversation content in the first report.

AutoYou prioritizes authentication, pairing, local data exposure, command/tool execution, message-disclosure, and release-signing issues.

**Networking & relays.** Peer traffic for data and voice is end-to-end encrypted between your own devices. AutoYou connection helpers only forward already-encrypted packets and cannot read or modify your data; they see connection metadata only.

For privacy requests or data-handling questions, contact `privacy@autoyou.me`.
